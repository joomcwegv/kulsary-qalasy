# Құлсары қаласы

Атырау облысы, Жылыой ауданының орталығы Құлсарыға арналған бір беттік ақпараттық сайт прототипі. Сайтта қаланың тарихы, көрікті орындары, демалыс аймақтары, ресми байланыстар мен пайдалы арналар жинақталған.

## Технологиялар

- React 19 және TypeScript
- Vite 7
- Tailwind CSS 4 және жеке CSS стильдері
- Lucide React белгілері

## Локальды іске қосу

Node.js орнатылған болуы керек.

```bash
npm install
npm run dev
```

Vite көрсеткен мекенжайды ашыңыз, әдетте `http://localhost:5173/`.

## Жинақтау

```bash
npm run build
npm run preview
```

Дайын нұсқа `dist/` бумасына жазылады. `vite-plugin-singlefile` JavaScript пен CSS-ті HTML ішіне біріктіреді, ал `public/` суреттері бөлек файл болып қалады.

## Құрылым

- `src/App.tsx` - бет бөлімдері, мәліметтер және сілтемелер.
- `src/index.css` - түстер, орналасу, анимациялар және мобильді бейімдеу.
- `public/images/` - жергілікті иллюстрациялар мен схемалық карта.
- `index.html` - бет атауы мен метадеректер.

## Ескерту

Бұл ресми мемлекеттік сайт емес, ақпараттық frontend-прототип. Өтініш қалдыру, карта және әлеуметтік арналар сыртқы сервистерге апарады. Ресми мәліметтерді [Жылыой ауданы әкімдігінің порталынан](https://www.gov.kz/memleket/entities/atyrau-zhylyoy) тексеріңіз.

Құлсары ата, Ақмешіт және кіреберіс фотолары сыртқы дереккөздерден жүктеледі. Басты, жастар және көл көріністері иллюстрациялық сипатта. Схемалық картадан Google Maps-тағы нақты орынға өтуге болады.
